# ARGI Chat Memory Example

[中文版本](README-zh.md)

This example demonstrates how to use the Chat Memory functionality.

> The ARGI version containing this dependency has not been officially released yet. If you want to experience this demo, you need to install it locally. If not, you can safely skip this without affecting the startup of other examples.
